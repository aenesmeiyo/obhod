## [1.0.0] — 2026-11-21

### Добавлено

- Первый релиз приложения «Обход» на Electron.
- Установка, запуск и обновление zapret-discord-youtube и tg-ws-proxy из официальных релизов.
- Две кнопки включения, фоновый запуск `winws.exe`, статус процессов.
- Game Filter и IPSet-режимы, совместимые с `service.bat`.
- Автопроверка обновлений с баннером и сохранением пользовательских настроек.
- Тест всех стратегий с проверками Discord, YouTube, Google и DNS.
- Подключение Telegram по `tg://proxy`, копирование ссылки.
- Диагностика окружения, журнал, трей, автозапуск.
- Тёмный Liquid Glass-интерфейс на glisse.
- GitHub Actions для сборки установщика и публикации релизов.
