# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.2] — 2026-11-21

### Исправлено

- Приложение больше не требует права администратора **при запуске** (манифест `asInvoker`).
  Раньше на системах с отключённым UAC или обычной учётной записью Windows не могла запустить
  `Obhod.exe` — процесс завершался без окна. Теперь окно открывается всегда, а права
  запрашиваются только для Zapret по кнопке «Перезапустить».
- Перезапуск с правами администратора переписан: новый процесс стартует после выхода старого и
  действительно запрашивает повышение прав (раньше `app.relaunch()` запускал копию без RunAs).
- Ошибки инициализации и загрузки интерфейса теперь пишутся в журнал и показываются диалогом или
  экраном ошибки с кнопками «Повторить» и «Открыть журнал», вместо бесконечного splash-экрана.
- Состояние приложения собирается отказоустойчиво: сбой чтения стратегий или конфига больше не
  блокирует запуск окна.
- Повреждённый `config.json` TG WS Proxy автоматически откладывается и создаётся заново.
- Определение прав администратора больше не зависит только от PowerShell.

### Изменено

- Установщик теперь **one-click и per-machine**: ставится без вопросов сразу для всех
  пользователей в `Program Files`, ярлыки создаются для всех.
- Обновлены README и заметки к релизу.

## [1.0.1] — 2026-11-21

### Изменено

- Вкладки в шапке теперь переключаются пружинной анимацией с liquid-glass-эффектом
  (glisse SegmentedControl): выделение плавно переезжает на выбранный раздел.
- Убраны дублирующие большие кнопки «Включить/Выключить» — управление осталось на тумблерах
  в шапке карточек.
- Убраны дублирующие статусы в hero-блоке: состояние видно рядом с тумблером.
- Карточки стали компактнее, нижние действия перенесены в футер карточек.
- Обновлены скриншоты в README.

## [1.0.0] — 2026-11-21

### Добавлено

- Первый релиз приложения «Обход» на Electron.
- Установка, запуск и обновление zapret-discord-youtube и tg-ws-proxy из официальных релизов.
- Две кнопки включения, фоновый запуск `winws.exe`, статус процессов.
- Game Filter и IPSet-режимы, совместимые с `service.bat`.
- Автопроверка обновлений с баннером и сохранением пользовательских настроек.
- Тест всех стратегий с проверками Discord, YouTube, Google и DNS.
- Подключение Telegram по `tg://proxy`, копирование ссылки.
- Диагностика окружения, журнал, трей, автозапуск.
- Тёмный Liquid Glass-интерфейс на glisse.
- GitHub Actions для сборки установщика и публикации релизов.
