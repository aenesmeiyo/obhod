# Обход 1.0.0

Первый публичный релиз.

## Что внутри

- Единый интерфейс для **zapret-discord-youtube** и **tg-ws-proxy**.
- Установка обоих компонентов из официальных релизов Flowseal.
- Две кнопки включения/выключения, фоновый запуск `winws.exe` без консольных окон.
- Автопроверка обновлений с баннером; замена файлов с сохранением Game Filter, IPSet и
  пользовательских списков.
- Game Filter: выкл / TCP / UDP / TCP+UDP, свои диапазоны портов.
- IPSet: «Список» / «Выкл» / «Любой», обновление списка IP.
- **Тест стратегий**: перебор всех `general*.bat`, проверки Discord, YouTube, Google и DNS,
  рейтинг и применение лучшей стратегии.
- Кнопка **«Подключить в Telegram»** и копирование `tg://proxy`-ссылки.
- Диагностика окружения, журнал событий, трей, автозапуск через Планировщик задач.
- Тёмный Liquid Glass-интерфейс с пружинными переключателями glisse.

## Установка

1. Скачайте `Obhod-Setup-1.0.0.exe` ниже.
2. Запустите установщик и подтвердите UAC при первом запуске приложения.
3. Скачайте Zapret и TG WS Proxy на главном экране.

Установщик не подписан сертификатом: SmartScreen может предупредить. «Подробнее» → «Выполнить в
любом случае».
