# Обход 1.0.4

Теперь приложение обновляет само себя: не нужно каждый раз качать установщик с GitHub.

## Что изменилось

- **Самообновление.** При запуске «Обход» тихо проверяет GitHub (это можно отключить в настройках),
  показывает баннер «Вышло обновление», скачивает установщик с прогрессом и предлагает
  «Перезапустить». После перезапуска открывается уже новая версия. Если обновление скачано, но
  вы просто закрыли приложение — оно установится при выходе.
- **Ручная проверка.** В настройках появился блок «Версия приложения» с текущей версией, кнопкой
  «Проверить» и статусом загрузки.
- **Заголовок «Заморозки»** в таблице теста больше не наезжает на «Фикс / слом»: колонки расширены,
  подписи не переносятся и не обрезаются.

Для установки обновления Windows один раз спросит UAC: установщик ставится для всех пользователей
в `Program Files`. Дальше всё происходит само.

> Поставить **1.0.4** нужно один раз вручную — в 1.0.3 механизма самообновления ещё не было.
> Начиная с 1.0.4 следующие версии будут приходить автоматически.

## Установка

1. Скачайте `Obhod-Setup-1.0.4.exe` ниже.
2. Запустите установщик; приложение обновится поверх 1.0.x, настройки и компоненты сохранятся.
3. При первом запуске подтвердите UAC.

Установщик не подписан сертификатом: SmartScreen может предупредить. «Подробнее» → «Выполнить в
любом случае».

## Контрольная сумма

SHA-256 установщика лежит в `SHA256SUMS.txt` рядом с файлом релиза. Проверить:

```powershell
Get-FileHash .\Obhod-Setup-1.0.4.exe -Algorithm SHA256
```
