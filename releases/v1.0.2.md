# Обход 1.0.2

Исправление запуска и установки.

## Почему приложение не запускалось

В 1.0.1 `Obhod.exe` был собран с манифестом `requireAdministrator`. Windows обязана повысить права
процесса **до** запуска кода приложения. Если UAC отключён, учётная запись не администратор или
система урезана, Windows не может показать запрос и просто не запускает `Obhod.exe` — без окна и без
записи в журнале приложения. Установщик при этом ставил приложение в профиль пользователя, поэтому
симптом выглядел как «установилось, но не открывается».

## Что исправлено

- **Запуск без прав администратора.** Манифест приложения теперь `asInvoker`: окно открывается
  всегда. Права нужны только Zapret — кнопка «Перезапустить» в баннере запускает приложение через
  `Start-Process -Verb RunAs` и действительно запрашивает UAC.
- **One-click установка для всех пользователей.** Установщик больше не спрашивает режим установки
  и папку: ставится сразу в `Program Files` для всех пользователей, ярлыки создаются на рабочем
  столе и в Пуске.
- **Диагностика запуска.** Ошибки инициализации, загрузки интерфейса и зависший renderer теперь
  попадают в `%LOCALAPPDATA%\Obhod\logs\app.log` и показываются диалогом/экраном ошибки с кнопками
  «Повторить» и «Открыть журнал», а не бесконечным splash-экраном.
- **Устойчивое состояние.** Сбой чтения стратегий или настроек больше не мешает открыть главное окно.
- **TG WS Proxy.** Повреждённый `config.json` откладывается в сторону и создаётся заново.
- **Определение прав.** Больше не зависит только от PowerShell: используется `whoami /groups`.

## Установка

1. Скачайте `Obhod-Setup-1.0.2.exe` ниже.
2. Запустите установщик и подтвердите UAC. Больше вопросов не будет: приложение поставится для всех
   пользователей в `Program Files`.
3. Запустите «Обход» из Пуска или с рабочего стола. Приложение откроется без запроса прав.
4. Для Zapret нажмите «Перезапустить» в баннере — Windows один раз запросит UAC. Прокси Telegram
   работает без прав администратора.

Если обновляетесь с 1.0.1, установщик поставит новую версию для всех пользователей. Старую
пользовательскую копию при желании можно удалить через «Параметры → Приложения».

## Контрольная сумма

SHA-256 лежит рядом с установщиком в `SHA256SUMS.txt`. Проверить:

```powershell
Get-FileHash .\Obhod-Setup-1.0.2.exe -Algorithm SHA256
```
