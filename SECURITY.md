# Безопасность

## Как сообщить об уязвимости

Не создавайте публичный Issue, если речь об уязвимости, которая может навредить пользователям.
Используйте [GitHub Security Advisories](https://github.com/aenesmeiyo/obhod/security/advisories/new)
или напишите владельцу репозитория приватно.

Приложите:

- версию приложения и Windows;
- шаги воспроизведения;
- возможные последствия;
- PoC, если он безопасен.

## Что важно знать

- Приложение запускается с правами администратора: это требование `winws.exe` и WinDivert.
- Компоненты `zapret-discord-youtube` и `tg-ws-proxy` скачиваются с официальных GitHub-релизов
  Flowseal; приложение не подменяет и не модифицирует их бинарники.
- Приложение не отправляет телеметрию. Сетевые запросы ограничены GitHub, проверками целей во время
  теста и локальным Telegram-прокси.
- Установщик не подписан коммерческим сертификатом. Проверяйте SHA-256 из `releases/SHA256SUMS.txt`.
